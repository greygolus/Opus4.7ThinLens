Sign convention: Light travels left to right. Positive f converging. Image distance v measured from lens; virtual image when v is on the object side. Dragging: Object arrow slides horizontally, arrow tip changes height. Lenses slide along axis. Aperture drags along axis; drag its edge to resize. Media: Each segment between elements can have an index n. Thin lens uses n₂/v − n₁/u = 1/f (paraxial power invariant). Stop selection: For a finite object, the aperture whose object-space image subtends the smallest half-angle from the axial object point is the effective stop. For an object at infinity, the smallest object-space pupil diameter wins.
